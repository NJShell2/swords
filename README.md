# Swords — a Bible memory game

Recite the verse from memory (or look it up in your physical Bible), flip the
card to check, score the round. Built for youth groups and family game nights.

- **Live:** https://njshell2.github.io/swords/
- **Translation:** New King James Version, via the licensed API.Bible feed
  (verse text is fetched at runtime; only references ship with the site)
- **Deck:** 268 verses across 25 themes
- **Scoring:** 1–8 players, names optional, +10 / +5 / +0 per round

## Setup for the host

The game needs a free API.Bible key once: sign up at https://api.bible,
copy the token, paste it into the game's Settings (gear icon). The game
remembers it and caches verse text locally after the first fetch.

## Files

- `index.html` — the whole game
- `swords-verses.js` — the 268-verse reference deck (generated by `build_verses.py`)
- `build_verses.py` — verse list source; rerun to regenerate the deck
